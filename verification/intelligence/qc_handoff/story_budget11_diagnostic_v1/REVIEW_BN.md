# Independent QC — নতুন genuine partial-text diagnostic

বিদ্যমান `intelligence.qc.v1` ও `professional_qc_v1` format/rubric reused। এটি নতুন প্রকৃত Story outputs দিয়ে সীমিত QC input preparation; নতুন model output নয়। আগের packets/পূর্ণ benchmark minimums বদলায়নি।

Reviewer শুধু review_packet.json পড়বেন; OWNER_EXPECTATIONS.json আগে খুলবেন না। Q1/Q2-এর মূল Bengali raw text অপরিবর্তিত। পরিচয় metadata বাদ; prose বা public repository lookup থেকে sample চেনা যেতে পারে—এটি সম্পূর্ণ double-blind নয়।

- প্রতিটি finding-এ sample ID, beat/path, exact quote, source evidence, observation, uncertainty ও targeted requirement দিন। Text QC-এর জন্য পুরো গল্পের ending দরকার নেই।
- Technical JSON/reference validity ও artistic plausibility আলাদা বিচার করুন। কোনো sample-কে আগে থেকেই clean ধরে নেবেন না।
- নিজেই story rewrite করবেন না; unsupported criticism/locked-source edit প্রস্তাব করবেন না।
- ছবি/video/audio নেই: সেই modality বা whole-story ending/complete arc সম্পর্কে abstain করুন।
- Form-এর reviewer identity, expertise, independence ও findings reviewer নিজে পূরণ করবেন। Owner review স্বাধীন expert review-এর বিকল্প বলে ধরে নেওয়া হবে না।
- দুই sample professional QC-এর text10/video3/audio3 minimum পূরণ করে না; এটি full calibration বা precision/recall result নয়। Existing balanced clean/defect tests বাদ দেয় না।
